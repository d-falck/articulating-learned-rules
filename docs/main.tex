\begin{abstract}
We evaluate whether language models can articulate the classification rules they learn from few-shot examples. Using 10 binary classification rules, we test both multi-choice articulation (selecting the correct rule from options) and free-form articulation (explaining in their own words). We measure three aspects of free-form articulation: similarity to ground-truth rules, usefulness for classifying new examples, and faithfulness to the model's actual behavior. On high-accuracy tasks (>90\%), models produce useful articulations but these often differ semantically from the true rules (similarity 0.4-1.0)—likely because alternative rules are indistinguishable on the data distribution. More surprisingly, articulations aren't always faithful to actual behavior (faithfulness 0.5-1.0), suggesting models add details during articulation that were previously fuzzy.
\end{abstract}

\section{Methodology}

\subsection{Data generation}

We use an LLM (Claude Sonnet 4.5) to generate text samples that satisfy or violate 10 binary classification rules like \textit{ends\_with\_question} (``The text ends with a question mark''), \textit{contains\_numbers} (``Contains at least one digit''), and \textit{is\_first\_person} (``Uses first-person pronouns''). The model generates examples about random topics, then validates its output via self-check. We create both isolated datasets (1,000 samples per rule) and combined datasets (1,000 samples with all 10 labels). See \cref{fig:generation_schematic} and appendix for details.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{generation_diagram.png}
    \caption{The process used to generate our dataset of classification tasks.}
    \label{fig:generation_schematic}
\end{figure}

\subsection{Articulation methods}

We test two approaches. In \textbf{multi-choice articulation}, we give models several candidate rule descriptions and ask them to select which they used. For \textit{ends\_with\_question}, options might be: (1) ``Ends with ?'' (correct), (2) ``Contains informal language'', (3) ``Uses first-person pronouns'', (4) ``Is very short''. We measure accuracy as the proportion of correct selections.

In \textbf{free-form articulation}, models explain rules in their own words (prompt: ``Explain what rule you used to classify this text. Provide a simple rule in one short sentence.''). For \textit{ends\_with\_question}, a model might say ``The text is true if it ends with a question mark'' or ``The text is true if it asks a question''.

We score free-form articulations with two metrics (\cref{fig:articulation_schematic}). \textbf{Similarity} uses a grader model to score semantic alignment with the true rule (0.0-1.0). \textbf{Usefulness} tests whether a grader can correctly classify 10 held-out examples using only the articulated rule.

\begin{figure}[htp]
    \centering
    \includegraphics[width=\textwidth]{articulation_diagram.png}
    \caption{Calculating the \textit{similarity} and \textit{usefulness} metrics for free-form articulations.}
    \label{fig:articulation_schematic}
\end{figure}

\subsection{Faithfulness}

We test whether models' behavior matches their articulated rules (\cref{fig:faithfulness_schematic}). After articulation, a grader model generates synthetic test cases designed to satisfy or violate the articulated rule. The original model then classifies these using its original few-shot context. \textbf{Faithfulness} is the proportion where the model's prediction matches the expected label based on its articulation.

\begin{figure}[htp]

    \includegraphics[width=\textwidth]{faithfulness_diagram.png}
    \caption{Measuring the \textit{faithfulness} of an articulation.}
    \label{fig:faithfulness_schematic}
\end{figure}

\subsection{Faithfulness}

Even on high-accuracy tasks (>90\%), faithfulness varies substantially (0.5-1.0, \cref{fig:faithfulness_by_accuracy}). This suggests models add specific details during articulation that were previously fuzzy—when tested on examples where these details matter, behavior may differ from the articulation.

\texttt{gpt-4.1} shows consistently higher faithfulness than other models. \Cref{fig:per_model_summaries} compares all three metrics at \(\texttt{n\_shot}=15\). Per-rule analysis in \cref{fig:faithfulness_by_rule}.

\section{Conclusion}

On high-accuracy classification tasks (>90\%), models produce useful articulations that correctly classify new examples. However, these articulations often differ semantically from the true rules (similarity 0.4-1.0), likely because multiple rules are functionally equivalent on the data distribution.

More surprisingly, articulations aren't always faithful to actual behavior (faithfulness 0.5-1.0). Models appear to add specific details during articulation that were previously fuzzy—when tested on examples where these details matter, behavior can be inconsistent with the articulation. Future work could explore regularizing toward simpler articulations to prevent over-specification.

\subsection{Next steps}

\begin{itemize}
    \item Try imposing more constraints on the articulation (forcing it to be even simpler than in the ``short'' case currently).
\end{itemize}

\section{Task Examples and Model Articulations}

Concrete examples of tasks, prompts, and articulations.

\subsection{Classification tasks}

We evaluate on 10 binary classification rules:

\begin{enumerate}
    \item \textbf{ends\_with\_question}: ``The text ends with a question mark (?)''
    \item \textbf{contains\_numbers}: ``The text contains at least one numerical digit (0-9)''
    \item \textbf{is\_title\_case}: ``Every word in the text starts with a capital letter''
    \item \textbf{contains\_quotes}: ``The text contains at least one quotation mark''
    \item \textbf{has\_many\_verbs}: ``The text contains at least 5 different verbs''
    \item \textbf{contains\_hashtag}: ``The text contains at least one hashtag symbol (\#)''
    \item \textbf{is\_very\_short}: ``The text is fewer than 7 words''
    \item \textbf{is\_first\_person}: ``The text uses first-person pronouns (I, me, my, we, our, us)''
    \item \textbf{has\_repeated\_word}: ``The text contains a word repeated 4-5 times consecutively''
    \item \textbf{contains\_rhyme}: ``The text contains multiple words that rhyme with each other''
\end{enumerate}

\subsection{Example few-shot prompt}

For the \textit{ends\_with\_question} task with 5 shots:

\begin{quote}
\small
\textit{Classify the following texts as true or false:}

\textit{Text: ``Do you enjoy reading books?''}

\textit{Label: true}

\textit{Text: ``I love coffee in the morning''}

\textit{Label: false}

\textit{Text: ``Where are my keys?''}

\textit{Label: true}

\textit{Text: ``The weather is nice today''}

\textit{Label: false}

\textit{Text: ``Can you help me with this?''}

\textit{Label: true}

\textit{Text: ``The music festival was amazing''}

\textit{Label: ?}
\end{quote}

\subsection{Example articulation prompt}

After the model classifies the test example, we prompt (short version):

\begin{quote}
\small
\textit{Explain what rule you used to classify this text. Provide a simple rule in one short sentence.}

\textit{Example format: ``The input is labeled as 'true' if the input is all lowercase.''}

\textit{Your rule:}
\end{quote}

\subsection{Example model articulations}

For \textit{ends\_with\_question}:

\begin{itemize}
    \item \textbf{High similarity (0.95)}: ``The text is labeled true if it ends with a question mark.''
    \item \textbf{Medium similarity (0.70)}: ``The text is true when it poses a question.''
    \item \textbf{Lower similarity (0.50)}: ``The text is true if it seeks information or clarification from the reader.''
\end{itemize}

All three may achieve high usefulness if they correctly classify held-out examples. The lower-similarity one identifies a semantic pattern (information-seeking) that correlates with the true syntactic rule but isn't identical.

For \textit{is\_first\_person}:

\begin{itemize}
    \item \textbf{High similarity (0.90)}: ``The text is true if it contains first-person pronouns like I, me, my, we, or our.''
    \item \textbf{Medium similarity (0.65)}: ``The text is true if the speaker is talking about themselves.''
\end{itemize}
